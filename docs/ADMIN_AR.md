# دليل الأدمن السريع — Iyma Sweet

## الدخول
`/admin` → `admin@iymasweet.com` / غيّري الباسورد فوراً بعد أول دخول.

## أهم الشاشات
1. **الطلبات** — متابعة الحالات، نسخ بيانات التوصيل، الخطوة التالية
2. **مراجعة الدفع** — قبول/رفض الإيصالات بسرعة
3. **جدول التجهيز** — اختاري يوم وشوفي تجميع الأصناف
4. **المنتجات / التصنيفات** — غيّري حالة التوفر من الجدول مباشرة
5. **الكوبونات**
6. **نصوص الواجهة** — أي جملة ظاهرة للعميل
7. **الإعدادات** — الألوان، الإعلان، إغلاق المتجر، بيانات البراند

## حالات المنتج
متاح الآن · متاح بكرة · بالحجز · نفد مؤقتاً (مع زر «نبّهني» للعميل)

## طرق الدفع
كاش / InstaPay / محفظة — فعّلي أو عدّلي الأرقام من الإعدادات لاحقاً (حالياً عبر seed + أوامر DB/Filament حسب المرحلة)

## نصيحة موبايل
الداشبورد متوافق مع الموبايل؛ راجعي إيصالات الدفع من التليفون يومياً.
